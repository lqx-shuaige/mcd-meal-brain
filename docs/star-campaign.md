## 0. 我们的反共识定位（所有文案的统一内核）

> 市面上的麦当劳 AI 都在帮你**一个人怎么点最省**；
> 没人管你**四个人凑一起怎么点最不乱**。

别人给你一个数字；我们给你**几套明显不同的取舍方案** + **一张谁该付多少的账单**。
拼单真正的痛不是贵，是乱：谁要辣谁不要、谁在减脂、谁要赠品、最后账怎么算——一次性解决。

核心差异点（用于对比表 / 反驳"又是个省钱工具"）：
- 🧠 **多目标最优，不是贪心一个低价**：NSGA-II 四目标帕累托（价格↓/热量↓/油炸↓/蛋白↑）+ 动态规划，最优性经 3000 组暴力穷举交叉验证 100% 一致。
- 🪑 **席位自适应，绝不凑数**：最省钱 / 最健康 / 最快三席必出，其余按"明显不同"才补（价格差≥¥1 或热量差≥75kcal），前沿退化就 1–2 套，宁缺毋滥。
- 💸 **拼单最后一公里——智能分账**：按成员画像把每个商品归属到人，券优惠按比例分摊，输出"谁该付多少"的逐人账单（整数分、尾差给小计最大者）。
- ✅ **真实核价 0% 偏差**：每个方案过官方 `calculate-price`，本地估算 ¥44.00 = 官方 ¥44.00。
- 🤝 **群体公平性**：一半要辣一半不要 → 自动检测冲突、给 A/B 双方案 + 妥协点；每方案带逐成员满足度（木桶效应取最低分）。
- 🔌 **零依赖 + 可移植**：纯 Python 标准库，符合 Agent Skills 开放规范，Claude Code / Cursor / Cline / WorkBuddy 都能加载。

## 1. V2EX / 程序员社区（技术向，讲清楚亮点）

**标题**：参加麦当劳程序员大赛，我写了个"多人拼单决策引擎"：NSGA-II 多目标寻优 + 动态规划，真实核价 0% 偏差

**正文**：

4 个人拼单，需求互相打架：一个减脂、一个不吃辣、一个要赠品、一个要便宜，预算还卡 100。
单人点餐只要回答"想吃什么"，多人要同时满足硬约束 / 软偏好 / 团队目标三层冲突。

我做的 mcd-meal-brain 在约束空间里做多目标寻优，并给出**可解释的取舍**：

- 最省钱求解：无界背包 DP + 券组合 DP（互斥/门槛/适用范围校验）
- 多目标收敛：NSGA-II 四目标帕累托（价格↓/热量↓/油炸↓/蛋白↑），固定种子可复现
- 最优性验证：与暴力穷举在同一搜索空间 100% 一致（3000 组交叉验证，固化在 CI）
- 真实数据：默认走麦当劳 MCP 实时链路（选址→菜单→门店券→营养），每个方案附 traceId 自证；兜底数据强制标注"非实时"
- 真实核价：过官方 `calculate-price`，偏差 0%
- 拼单分账：自动算清谁该付多少

4 人 demo：最省钱方案 ¥63 vs 朴素点法 ¥86，**省 26.7%**，同时满足"主食≥4 份 + 不辣 + 总预算 100"。

纯 Python 标准库、零第三方依赖、89 用例 pytest + GitHub Actions 全绿。
